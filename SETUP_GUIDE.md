# 📖 Повний посібник із налаштування та запуску (SETUP GUIDE)

Для багатокористувацької панелі з входом через Google та розгортанням на Render дивіться [Render + Supabase](docs/RENDER_SETUP.md). Цей посібник описує налаштування старого локального CLI.

Цей документ містить покрокову інструкцію: де отримати кожне значення для файлу `.env`, як налаштувати Google Cloud і Telegram, що саме публікувати в Google Classroom для викладачів кафедри та як перевірити готовність системи.

## 1. Налаштування файлу .env

Створіть або відкрийте файл `.env` у корені проєкту (`C:\Users\vadym\Downloads\ai-bird-secretary\.env`).

Нижче наведено зразок із детальним описом кожного параметра:

```env
# 1. Шляхи до файлів ключів Google
GOOGLE_CREDENTIALS_FILE=credentials.json
GOOGLE_TOKEN_FILE=token.json

# 2. Google Classroom
CLASSROOM_COURSE_ID=748291048291
ASSIGNMENT_NAME="Інформація про науково-дослідну роботу"

# 3. Telegram-сповіщення для завідувача кафедри
TELEGRAM_BOT_TOKEN=7123456789:AAFlkJHGfdsaQWERTYuiop1234567890
HEAD_OF_DEPT_CHAT_ID=123456789

# 4. Email-адреси для розсилки (Gmail)
HEAD_OF_DEPT_EMAIL=head.department@university.edu.ua
SCI_DEPT_EMAIL=s_galina_2005@ukr.net

# 5. Ідентифікатори Google Таблиць зі статичними планами
STATIC_PLAN_SHEET_ID=1A2B3C4D5E6F7G8H9I0J_sheet_id_plan
STATIC_SCI_PLAN_SHEET_ID=1Z2Y3X4W5V6U7T8S9R0Q_sheet_id_sci_plan

# 6. Папка Google Диска для збереження зведених звітів
MASTER_OUTPUT_FOLDER_ID=1FolderIdGoogleDriveAbcDefGhi

# 7. (Опціонально) Ключ Groq AI для текстового аналізу та резюме
GROQ_API_KEY=gsk_your_actual_groq_key_here
```

### 📋 Таблиця-шпаргалка параметрів:

| Змінна в `.env` | Де взяти / Що вписати | Приклад значення |
|---|---|---|
| `GOOGLE_CREDENTIALS_FILE` | Назва файлу OAuth Client ID JSON з Google Cloud Console (покласти в корінь проекту) | `credentials.json` |
| `GOOGLE_TOKEN_FILE` | Створюється **автоматично** командою `npm run auth:init` | `token.json` |
| `CLASSROOM_COURSE_ID` | Числовий ID курсу в адресному рядку браузера: `classroom.google.com/c/XXXXXX` | `748291048291` |
| `ASSIGNMENT_NAME` | Точна назва завдання в лапках (обов'язково збігається з назвою в Класі!) | `"Інформація про науково-дослідну роботу"` |
| `TELEGRAM_BOT_TOKEN` | Токен бота, отриманий у Telegram від `@BotFather` | `7123456789:AAFlkJ...` |
| `HEAD_OF_DEPT_CHAT_ID` | Telegram Chat ID завідувача кафедри (дізнатися через `@userinfobot`) | `123456789` |
| `HEAD_OF_DEPT_EMAIL` | Особиста/робоча пошта завідувача кафедри для звітів та копій | `head@univ.edu.ua` |
| `SCI_DEPT_EMAIL` | Офіційна пошта наукового відділу університету (з лекції Ірини Анатоліївни) | `s_galina_2005@ukr.net` |
| `STATIC_PLAN_SHEET_ID` | ID Google Таблиці «План роботи кафедри» (з URL таблиці) | `1BxiMVs0XRA5nFM...` |
| `STATIC_SCI_PLAN_SHEET_ID` | ID Google Таблиці «План наукової роботи кафедри» (з URL таблиці) | `1FAIpQLScJ8a...` |
| `MASTER_OUTPUT_FOLDER_ID` | ID папки на Google Drive, куди бот зберігатиме готові зведені звіти | `1a2B3c4D_Folder...` |
| `GROQ_API_KEY` | Безкоштовний ключ API з сайту `console.groq.com` | `gsk_AbCdEf123...` |

## 2. Отримання Google Credentials (OAuth2)

1. Відкрийте [Google Cloud Console](https://console.cloud.google.com/).
2. Створіть новий проєкт (наприклад: `academic-secretary`).
3. У розділі **APIs & Services > Library** увімкніть 4 API:
   - **Google Classroom API**
   - **Google Drive API**
   - **Google Sheets API**
   - **Gmail API**
4. У розділі **APIs & Services > OAuth consent screen**:
   - Оберіть **External** (або Internal для G-Suite організації).
   - Вкажіть назву застосунку та ваш контактний email.
   - У вкладці **Test Users** обов'язково додайте свій Google-акаунт (і пошту завідувача).
5. У розділі **APIs & Services > Credentials**:
   - Натисніть **Create Credentials > OAuth client ID**.
   - Application type: **Desktop app**.
   - Натисніть **Create**, завантажте отриманий файл JSON.
   - Перейменуйте його на `credentials.json` і покладіть у корінь папки проєкту `ai-bird-secretary/`.

## 3. Налаштування Telegram-бота

1. Відкрийте Telegram і знайдіть офіційного бота **`@BotFather`**.
2. Надішліть команду `/newbot`.
3. Вкажіть ім'я бота (наприклад, `Кафедральний Секретар`) та username (наприклад, `dept_secretary_2026_bot`).
4. Скопіюйте отриманий **HTTP API Token** і вставте в `.env` у поле `TELEGRAM_BOT_TOKEN`.
5. **Як дізнатися `HEAD_OF_DEPT_CHAT_ID`:**
   - Нехай завідувач кафедри (або ви для тесту) відкриє в Telegram бота **`@userinfobot`** або **`@getmyid_bot`** і натисне `/start`.
   - Бот надішле числовий `Id` (наприклад, `123456789`). Вставте його в `HEAD_OF_DEPT_CHAT_ID`.
   - **Важливо:** Завідувач повинен відкрити вашого створеного бота і натиснути кнопку **`Start`** (інакше бот не зможе написати йому першим).

## 4. Ідентифікатори Google Drive та Sheets

### Як знайти ID таблиці (`STATIC_PLAN_SHEET_ID` та `STATIC_SCI_PLAN_SHEET_ID`):
Відкрийте потрібну Google Таблицю у браузері. Її посилання має вигляд:
```text
https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms/edit#gid=0
                                        ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
                                                    Ось це і є SHEET_ID
```
Скопіюйте значення між `/d/` та `/edit` і вставте у відповідну змінну.

### Як знайти ID папки на Google Drive (`MASTER_OUTPUT_FOLDER_ID`):
1. Створіть на Google Drive папку (наприклад: `Звіти кафедри 2026`).
2. Відкрийте її. Посилання в браузері буде:
```text
https://drive.google.com/drive/folders/1w5m7u3d_9eP1kQrS0_FolderIdExample
                                       ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
                                              Ось це FOLDER_ID
```
Скопіюйте його в `MASTER_OUTPUT_FOLDER_ID`. Усі сформовані зведені звіти кафедри автоматично зберігатимуться в цю папку.

## 5. Отримання ключа Groq AI

1. Перейдіть на [console.groq.com](https://console.groq.com/).
2. Увійдіть за допомогою Google або GitHub.
3. У бічному меню перейдіть в **API Keys**.
4. Натисніть **Create API Key**, скопіюйте ключ вигляду `gsk_...`.
5. Вставте його в `GROQ_API_KEY` у файлі `.env`.
*(Ключ дає безкоштовний доступ до моделі `qwen/qwen3.8-27b`, яка здійснює інтелектуальний аналіз та генерує аналітичне резюме).*

## 6. Публікація завдання в Google Classroom

Щоб система автоматично підхопила завдання, його потрібно правильно опублікувати.

### Крок 6.1: Налаштування курсу в Google Classroom
1. Створіть курс або відкрийте існуючий загальнокафедральний курс.
2. Подивіться на адресу в браузері: `https://classroom.google.com/c/748291048291`.
3. Число `748291048291` впишіть у `CLASSROOM_COURSE_ID` у вашому `.env`.
4. Переконайтеся, що всі викладачі кафедри приєднані до курсу в ролі **«Студенти» (Students)**, щоб система могла бачити їхні здачі робіт.

---

### Крок 6.2: Створення завдання (Assignment)
1. У курсі перейдіть на вкладку **«Завдання» (Classwork)** -> натисніть **«Створити» > «Завдання» (Create > Assignment)**.
2. **Назва (Title):** обов'язково вкажіть точну назву:
   ```text
   Інформація про науково-дослідну роботу
   ```
3. **Термін здачі (Due Date):**
   - Встановіть кінцеву дату (наприклад: *16 листопада 2026 року*) та час (наприклад: *23:59*).
   - Система щодня обчислює кількість днів до цієї дати:
     - За 3 дні (Т-3) формує попередній звіт і попереджає боржників.
     - За 1 день (Т-1) здійснює звірення та перерахунок.
     - У день дедлайну відправляє фінальний звіт у науковий відділ.

---

### Крок 6.3: Що вставити в опис завдання (Текст для викладачів)
Скопіюйте цей текст безпосередньо в поле **«Вказівки» (Instructions)** завдання:

```markdown
Шановні викладачі кафедри!

Просимо надати індивідуальні звіти про науково-дослідну роботу за звітний період відповідно до офіційних форм МОН та університету.

📌 ВИМОГИ ДО ЗАПОВНЕННЯ:
1. Заповніть офіційний Excel-бланк або відповідні Word-додатки (Додатки 1-28), прикріплені нижче.
2. У разі відсутності показника обов'язково ставте прочерк "-" або фразу "інформація відсутня" (система зарахує їх як 0).
3. Якщо у вас є статті Scopus/WoS, патенти, нагороди, дипломи або виступи на конференціях — обов'язково прикріпіть до відповіді підтверджуючі фотозвіти чи сертифікати у форматі .JPEG/.JPG.

⚠️ Кінцевий термін здачі: до встановленого дедлайну.
За 48 годин до дедлайну формується попередній звіт, а список викладачів, які не надали інформацію, передається завідувачу кафедри.
```

---

### Крок 6.4: Які файли прикріпити до завдання як шаблони
При створенні завдання натисніть кнопку **Прикріпити файл** і додайте матеріали з локальної папки проєкту `templates/`:
1. `templates/2_Інформ._про_наук.роб_(бланк)_2026.xlsx` — офіційний бланк звіту (28 розділів).
2. `templates/ІНСТРУКЦІЯ.docx` — інструкція щодо заповнення додатків.
3. Файли додатків із папки `templates/addons/` (наприклад: `Додаток_1.docx` — монографії, `Додаток_3.docx` — публікації Scopus/фахові, `Додаток_10.docx` — патенти, `Додаток_18.docx` — гранти).

Натисніть **«Опублікувати» (Assign)**.

## 7. Первинний запуск та перевірка

Після того, як ви заповнили `.env` та розмістили `credentials.json`:

### Крок 7.1: Авторизація облікового запису Google
Виконайте команду в терміналі:
```bash
npm run auth:init
```
* Відкриється браузер для входу у ваш Google-акаунт.
* Надайте дозвіл для Classroom, Drive, Sheets та Gmail.
* У корені автоматично з'явиться файл `token.json`.

### Крок 7.2: Комплексна діагностика підключень (Healthcheck)
```bash
npm run check
```
Система перевірить валідність ключів, наявність токенів та зв'язок із Telegram. Усі пункти мають відобразити `[OK]`.

### Крок 7.3: Запуск Панелі керування
Двічі клацніть файл у корені проєкту:
```text
🚀_Запустити_Панель_Керування.bat
```
Або введіть команду:
```bash
npm run serve
```
Відкрийте `http://localhost:3000` у браузері. Панель потребує змінних hosted-конфігурації, міграцій PostgreSQL і входу через Google, описаних у [Render + Supabase](docs/RENDER_SETUP.md). Її кнопки формують звіти та надсилають реальні сповіщення.
